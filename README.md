# CSV Form Data Visualization

Upload a CSV file and automatically generate interactive dashboards for each column.  
Numeric columns are shown as line charts, and categorical columns as bar charts.  

**Tech Stack:** HTML, CSS, JavaScript, Chart.js, PapaParse  

**Try it live:** [https://lavanyaamara.github.io/csv-form-data-visualization/](https://lavanyaamara.github.io/csv-form-data-visualization/)
